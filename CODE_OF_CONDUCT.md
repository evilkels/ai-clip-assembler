# Code of Conduct

AI Clip Assembler aims to be a practical, respectful open source project for people working on local-first video tools.

## Expected behavior

- Be direct, constructive, and specific.
- Assume good intent, but correct problems clearly.
- Keep discussions focused on the project and its users.
- Respect privacy, especially around source footage, local paths, credentials, and unpublished creative work.

## Unacceptable behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing another person's private information, footage, credentials, or local file paths without permission.
- Spam, trolling, or repeatedly derailing technical discussions.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; reject contributions; or block participants when behavior harms the project or its community.

To report a conduct issue, contact the maintainer through the GitHub profile associated with this repository. Include links or screenshots where possible.
