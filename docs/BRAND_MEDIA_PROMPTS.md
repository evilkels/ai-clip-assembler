# Brand and Media Prompt Ideas

Use these prompts to generate project media separately. Keep generated assets reviewable and commit only the final selected files.

## Logo directions

### 1. App icon

```text
Create a modern macOS-style app icon for "AI Clip Assembler", a local-first desktop video editor. Concept: a film strip turning into a clean timeline with one subtle AI spark or node pattern. Professional creator-tool aesthetic, simple silhouette, high contrast, readable at small sizes, no text, no camera lens cliche, no cloud symbol. Use a balanced palette with charcoal, white, teal, and a small amber accent. Output as a square icon on a transparent background.
```

### 2. Open source project mark

```text
Design a clean vector-style logo mark for an open source project named "AI Clip Assembler". Show the idea of many messy source clips becoming one organized edit timeline. Minimal geometric shapes, friendly but professional, suitable for GitHub README, stickers, and app splash screen. Avoid gradients as the main identity, avoid stock media icons, avoid text. Transparent background.
```

### 3. Wordmark exploration

```text
Create a horizontal wordmark concept for "AI Clip Assembler". Pair a compact timeline/film-strip symbol with readable typography. The mood is local-first, precise, editor-friendly, and open source. Use restrained colors: near-black text, off-white background, teal accent, amber marker dot. Make it suitable for a GitHub README header and website navigation.
```

## README hero images

### 1. Product hero

```text
Create a polished hero image for an open source desktop app called "AI Clip Assembler". Show a realistic desktop video editor interface with a source clip grid, review decisions, timeline tracks, and export panel. The app is local-first and privacy-focused, so avoid cloud imagery. Use real-feeling UI details without readable fake text. Style: modern creator software, calm, practical, high-end, macOS desktop environment, 16:9.
```

### 2. Problem/solution visual

```text
Create a visual for a GitHub README that communicates raw video chaos becoming an editable timeline. Left side: many unorganized MP4 clips from drone/action footage. Right side: a clean timeline with selected highlights ready for Final Cut Pro or DaVinci Resolve. No marketing slogans, no text overlays, no cloud upload symbols. Professional open source software aesthetic, 16:9.
```

### 3. Privacy-first visual

```text
Create a tasteful illustration for a local-first AI video editor. Show video clips being analyzed on a personal laptop with subtle local processing indicators, not uploaded to a cloud. Include timeline editing and export cues. Clean technical illustration, not cartoonish, no text, no padlock cliche, balanced neutral palette with teal and amber accents, 16:9.
```

## Screenshots and social cards

### GitHub social preview

```text
Create a GitHub social preview image for "AI Clip Assembler". Visual concept: raw MP4 clips flow into an organized edit timeline. Include a small app-logo area but no small unreadable UI text. Professional open source project style, high contrast, works at 1280x640, no people, no cloud icons.
```

### Release banner

```text
Create a release announcement banner for an early MVP of a local-first AI video editor. Show an editable timeline, accepted clip cards, and export destinations for Final Cut Pro, DaVinci Resolve, and EDL represented as simple abstract icons. No readable brand logos unless legally safe. Clean desktop software look, 16:9.
```

### Documentation thumbnail

```text
Create a documentation thumbnail for setup and developer docs of a local-first video editor. Show terminal, Electron app window, and video timeline in a neat developer workspace. Avoid text-heavy UI, avoid brand logos, keep it clear and practical. 16:9.
```

## Asset checklist

- `assets/logo.svg` or `assets/logo.png` - project logo for README.
- `assets/icon.png` - square app icon source.
- `assets/social-preview.png` - GitHub repository social preview, 1280x640.
- `assets/readme-hero.png` - optional README hero image.
- `assets/screenshots/` - real app screenshots once the UI is ready for public inspection.

Generated media should not imply cloud processing or fully autonomous editing. The core message is: local footage, AI-assisted first pass, human-controlled editable timeline.
