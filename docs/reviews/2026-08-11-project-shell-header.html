Project shell header and sidebar

Four ordered task commits implement the bounded shell layout, stable project rows, and recents-label rename flow.

Verdict: complete against the specified scope.

Summary

The Import page now shrinks within the main column and gives genuinely wide tables their own horizontal scroll container. Project identity has one full-width shell row above the banner slot. Recent projects sort alphabetically without changing recency persistence, and rename edits only the display label in the recents file.

The implementation adds no dependencies and makes no backend changes. The existing update-check components and tests were left unchanged. Every new IPC handler calls assertApplicationSender.
